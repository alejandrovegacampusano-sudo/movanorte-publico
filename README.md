# Movanorte · sitio web

Sitio público de Movanorte, automatización para negocios en Iquique.

- `index.html`: la página completa, autocontenida (tipografías y logo embebidos).
- `og.png`: imagen de previsualización al compartir el enlace.
- `.github/workflows/pages.yml`: publica el sitio en GitHub Pages con cada cambio en `main`.

El dominio movanorte.cl aún no está registrado; cuando exista se conecta desde Settings → Pages → Custom domain.

Publicado en: https://alejandrovegacampusano-sudo.github.io/movanorte-publico/
